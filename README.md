# Microbot meshes

Binary CAD assets for the microbots project, kept on this orphan branch so they stay out of `main`'s history.

- `microbot_v1/microbot_v1_stl.zip`: all STL files (16 assemblies + 5 parts)
- `microbot_v1/microbot_v1_step.zip`: all STEP files
- `microbot_v1/stl/`: the STL files unzipped, for single-file downloads

Download on a Raspberry Pi:

    wget https://raw.githubusercontent.com/ItsAdarsh008/microbots/meshes/microbot_v1/microbot_v1_stl.zip
