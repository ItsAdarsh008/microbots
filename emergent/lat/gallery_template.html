Lattice Swarm Gallery

Every lattice run, each replayed on the same six shapes: tower, gamma, bridge, tee, mushroom and tree. The swarm starts as a pile on the left and is trained only to fill the target. Nothing in the objective mentions supports, build order or falling. Mushroom and tree are held out: no run trained on them.

A run works when it fills more than the target could keep on its own (the perfect-placement reference). Numbers in green beat that reference and numbers in red fall short of it.

Reading the GIFs

L (cantilever limit) is how many cells a bot can stick out sideways and stay held. Unheld bots fall one cell per step. Each GIF shows the build steps, then gravity alone with no actions. It pauses on the final state.

Chips list what differs from the base run (L = 1, 30% spare bots, 8 memory channels, 160 build steps, all shape families).
